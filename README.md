# Aviasurf for Gemini CLI

[![M8ven Score](https://m8ven.ai/badge/mcp/aviasurf-aviasurf-gemini-extension-101w0n?v=e5baaab713f77edfd4dafe8abe3096ee)](https://m8ven.ai/mcp/aviasurf-aviasurf-gemini-extension-101w0n?s=readme)

Official Aviasurf extension for Gemini CLI.

Use Aviasurf to search and compare indicative flight prices, explore price calendars, compare airports, discover destinations, inspect routes, and continue to live flight search.

## MCP server

This extension connects to the official Aviasurf remote MCP server:

https://mcp.aviasurf.com/mcp

No authentication is required.

## Example prompts

- Find indicative flight prices from London to Paris for a one-week round trip next month.
- Show me the cheapest observed dates from New York to Rome over the next six months.
- Compare the indicative prices for the airports serving London and Paris.
- Find direct economy flights with baggage from London to Barcelona next month.
- Show me affordable island destinations from London next month.
